## 🎯 Objetivo do Trabalho

O objetivo deste trabalho é analisar os dados das corridas dos táxis amarelos de Nova York, referentes a janeiro de 2024, utilizando técnicas de Big Data e análises estatísticas.

A partir de aproximadamente 2,96 milhões de registros, buscamos identificar padrões de demanda, analisar a receita das corridas, compreender os fatores que influenciam os valores cobrados e avaliar a qualidade dos dados.

O estudo também envolve o tratamento e a limpeza da base, a aplicação de testes estatísticos e a identificação de possíveis inconsistências, contribuindo para uma melhor compreensão dos dados e para a tomada de decisões na gestão da frota de táxis.
